Flutter is back at Google I/O on May 19-20![Register now](https://io.google/2026/?utm_source=flutter&utm_medium=embedded_marketing&utm_campaign=flutter)

Due to security around[local network permissions in iOS 14 or later](https://developer.apple.com/news/?id=0oi77447),
                  you must accept a permission dialog box to enable
                  Flutter debugging functionalities such as hot-reload
                  and DevTools.

![Screenshot of &quot;allow network connections&quot; dialog](https://docs.flutter.dev/assets/images/docs/development/device-connect.png)

This affects debug and profile builds only and won't
                  appear in release builds. You can also allow this
                  permission by enabling**Settings > Privacy > Local Network > Your App**.

Unless stated otherwise, the documentation on this site reflects Flutter 3.41.5.
